# Pumice

An independent experiment building a lightweight desktop notes application for plain-Markdown vaults, informed by Mike's Pumice crew roles. Mike's checkout is a separate project and remains untouched.

## First milestone

Open a copied test vault, browse and edit Markdown files, and save without corrupting notes. Add search after the basic path works. External changes, write failures, and recovery need explicit tests. Broader features remain part of the longer-term direction, not the initial milestone.

This project is not yet runnable. Do not test on an irreplaceable vault.
